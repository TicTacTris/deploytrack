# DeployTrack

DeployTrack is a production-style DevOps portfolio project built through
incremental, reviewed changes. The application is intentionally small so the
project can focus on delivery, infrastructure, security, and operations.

## Goal

Demonstrate how to build, test, package, provision, deploy, observe, and
troubleshoot a web service using practices found in modern DevOps teams.

## Planned stack

- Python and FastAPI
- PostgreSQL
- Docker and Docker Compose
- Nginx
- GitHub Actions
- AWS and Terraform
- Prometheus, Grafana, and CloudWatch
- Kubernetes fundamentals

## Delivery approach

Work is delivered in small commits on short-lived branches and reviewed through
pull requests before reaching `main`. Credentials and environment-specific
configuration must not be committed to the repository.
